# Conciliação PC vs NF

Crie um sistema automatizado que compare o xml da nota fiscal com esse modelo de pedido da concinco, cruzando as informações do EAN, descrição, quantidade faturada na nota e quantidade do pedido de compra.

Mostrar apenas o histórico das conciliações dos últimos 7 dias, cruzar as informações dos códigos DUN/EAN da nota e comparar com o pedido, se na nota xml vier o dun e ean junto, faça o cruzamento com o pedido do ean.

incluir a embalagem da nota fiscal e do pedido no sistema para conciliação.

Exiba um layout moderno com opção de escuro e claro para visualização do sistema.
